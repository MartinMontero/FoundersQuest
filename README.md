# Founder's Quest

A static tool that helps founders test their assumptions with evidence instead of opinion — validated learning over completed checkboxes.

## Develop

```bash
npm install
npm run dev      # fast UI iteration
npm run build    # production build → dist/
```

## Deploy

Cloudflare Pages (static `dist/` + a Pages Function at `functions/api/council.js`).
See the local deploy runbook — it is intentionally not committed to this public repo.
